Comment jouer au Tectonic

Touchez une case, puis un chiffre du pavé pour l’y poser ; touchez de nouveau le même chiffre pour l’effacer. Le pavé grise les chiffres trop grands pour le bloc de la case. Le mode Notes permet d’annoter plusieurs candidats dans une case vide. Les chiffres de départ, en gras, ne bougent pas. La grille est résolue quand elle est pleine et respecte les règles : un bloc de N cases contient les chiffres de 1 à N, et deux cases qui se touchent — même par un coin — ne portent jamais le même chiffre.

Trois techniques pour avancer

  • Les blocs d’une case : ils contiennent forcément un 1. Commencez par eux.
  • Le voisinage : un chiffre posé interdit ce même chiffre aux huit cases qui l’entourent. Cherchez, dans un bloc, la seule case où un chiffre peut encore aller.
  • Les notes : dans un bloc de deux cases, notez « 1 2 » partout ; dès qu’une des deux touche un 1, elle porte le 2.

La grille du jour

Chaque jour, une grille 12×12 de niveau Expert, la même pour tous les joueurs, sur ce site comme dans l’app Zellige. Elle change à minuit, à votre heure. Terminez-la plusieurs jours d’affilée pour faire grimper votre série.

Questions fréquentes

Tectonic, Suguru : quelle différence ?
Aucune : Suguru est le nom japonais d’origine du jeu, Tectonic celui sous lequel on le trouve dans les magazines de jeux en France et en Belgique.
Le jeu est-il gratuit ?
Oui, entièrement gratuit, sans inscription et sans publicité sur cette page. Vos temps et votre série restent dans votre navigateur : rien n’est envoyé à un serveur.
Faut-il deviner ?
Jamais. Chaque grille est générée puis vérifiée par un solveur pour n’avoir qu’une seule solution : il existe toujours une case qui se déduit.
Puis-je jouer hors connexion ?
La version web demande une connexion pour charger la page. L’app iPhone et Android se joue hors ligne et ajoute le mode histoire, dont les grilles grandissent du 5×5 jusqu’au 12×12, et les classements.
